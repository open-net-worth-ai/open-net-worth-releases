# Open Net Worth — desktop downloads

Your wealth, on your computer.

This repository only hosts the signed, notarized desktop app and its update feed.

## Download

**macOS (Apple Silicon):** [Open-Net-Worth-mac-arm64.dmg](https://github.com/open-net-worth-ai/open-net-worth-releases/releases/latest/download/Open-Net-Worth-mac-arm64.dmg)

Open the `.dmg` and drag **Open Net Worth** to Applications. Installed apps check for
updates automatically and offer **Restart to Update** when a new version is ready.

All versions: [Releases](https://github.com/open-net-worth-ai/open-net-worth-releases/releases)

More at [opennetworth.ai](https://opennetworth.ai).
